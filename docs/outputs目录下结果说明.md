# outputs 实验结果说明

`outputs/` 目录保存整个多模态情感识别项目运行产生的实验结果。

说明原则：

-   对**图表类结果**说明其表达内容和用途；
-   对**同类型数据文件**仅说明所在目录和数据用途，不逐个展开。

## 总体结构

``` text
outputs/

├── q1/   # 问题1：多模态特征提取与时序对齐
├── q2/   # 问题2：鲁棒情感预测模型训练与实验
└── q3/   # 问题3：可解释性分析与证据定位
```

------------------------------------------------------------------------

# 二、Question 2 输出结果

目录：

``` text
outputs/q2/
```

用于保存鲁棒多模态融合模型训练、评价和实验结果。

## runs/

保存不同模型训练结果。

包含：

-   MRRF模型
-   基线模型
-   消融模型

主要文件：

-   checkpoint.pt：模型参数
-   metrics.json：训练和测试指标
-   config.json：实验配置

------------------------------------------------------------------------

## experiments/

保存实验结果：

包括：

-   robustness：缺失模态鲁棒性实验
-   missing_duration：缺失持续时间实验
-   ablation：消融实验
-   baselines：基线模型比较
-   repeats：多随机种子实验
-   tuning：超参数搜索

------------------------------------------------------------------------

## tuning/

保存超参数搜索结果：

包括：

-   最优配置
-   搜索过程
-   实验记录

------------------------------------------------------------------------

## analysis/

保存统计分析结果。

主要内容：

-   不同模型性能比较
-   错误案例分析
-   三随机种子统计结果

------------------------------------------------------------------------
