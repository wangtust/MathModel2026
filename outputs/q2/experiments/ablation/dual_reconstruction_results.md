# 双路重建探索实验

新增变体在不覆盖主模型检查点的条件下，把每个模态的掩码自注意力编码与 MulT 跨模态序列重建融合。
仅在人工遮挡且原生可用的位置计算重建损失；输入、划分、选模规则与原 MRRF 完全相同。

| 指标 | 原 MRRF | 双路重建 |
|---|---:|---:|
| 三种子验证选模分数 | 0.405 ± 0.008 | 0.404 ± 0.013 |
| 三种子验证 clean Macro-F1 | 0.599 ± 0.008 | 0.602 ± 0.014 |
| 三种子留出测试 clean Macro-F1 | 0.588 ± 0.029 | 0.603 ± 0.030 |
| 种子 2026 验证选模分数 | 0.405 | 0.397 |
| 种子 2026 验证 clean Macro-F1 | 0.604 | 0.589 |
| 种子 2026 验证 clean MAE | 0.594 | 0.597 |
| 种子 2026 验证文本缺失 60% Macro-F1 | 0.521 | 0.557 |
| 种子 2026 验证文本缺失 60% MAE | 0.661 | 0.625 |
| 种子 2026 留出测试 clean Macro-F1 | 0.563 | 0.576 |
| 种子 2026 留出测试 clean MAE | 0.653 | 0.654 |

表中未注明‘三种子’的行均为种子 2026 的条件对照；三种子逐项数值见 `dual_reconstruction_three_seed.csv`。
全 55 条固定验证条件见 `dual_reconstruction_grid.csv`，缺失比例对比见 `fig18_dual_reconstruction.pdf`。
这是结构补全后的探索实验；图 18 的场景热图只有种子 2026，三种子均值也不能证明结构优越性。附件三仍采用既有预先确定规则选定的主模型。
